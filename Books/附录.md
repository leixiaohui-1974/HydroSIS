# 附录

本附录整理 HydroSIS 仓库中最常用的配置模板、核心 API、示例数据字典、运行脚本与名词缩写，方便读者在阅读前述章节后快速查找操作细节与扩展入口。所有资料均来源于仓库内现有源码、配置与示例资源，便于直接引用或复制到新项目中。

## 附录A 配置示例与模板

### A.1 模板总览

HydroSIS 在 `config/example_model.yaml` 中提供了覆盖流域划分、产流/汇流模块、参数分区、I/O 目录、情景与评价配置的完整模板，可直接作为新工程的起点。【F:config/example_model.yaml†L3-L131】README 也同步给出了目录结构示意，便于在初始化仓库时创建必要的子目录。【F:README.md†L15-L48】

| 配置段落 | 关键字段 | 说明 |
| --- | --- | --- |
| `delineation` | `dem_path`、`pour_points_path`、`precomputed_subbasins` | 绑定 DEM、控制点及预划分子流域，允许为每个子流域设置默认模型组合。【F:config/example_model.yaml†L3-L33】 |
| `runoff_models` | `model_type`、`parameters` | 定义可复用的产流模块及参数集合（如 SCS 曲线数、XinAnJiang、HYMOD 等），可在参数区或情景中引用。【F:config/example_model.yaml†L34-L69】 |
| `routing_models` | `model_type`、`parameters` | 描述 Muskingum 等汇流算法及其时间步长、权重等参数。【F:config/example_model.yaml†L70-L82】 |
| `parameter_zones` | `control_points`、`parameters` | 以控制点划分参数区，并声明默认的产流/汇流模型绑定关系。【F:config/example_model.yaml†L84-L103】 |
| `io` | `precipitation`、`results_directory` 等 | 约定强制输入/输出路径，确保工作流脚本能在统一目录下生成成果。【F:config/example_model.yaml†L104-L109】 |
| `scenarios` | `modifications` | 针对指定子流域覆写模型 ID，实现情景模拟。支持同时调整多个子流域参数。【F:config/example_model.yaml†L111-L122】 |
| `evaluation` | `metrics`、`comparisons` | 配置自动化指标和情景对比计划，为报告生成提供结构化输入。【F:config/example_model.yaml†L123-L131】 |

### A.2 YAML/JSON 双格式维护

`ModelConfig.from_yaml` 默认依赖 PyYAML；若运行环境缺少该依赖，可直接改用随仓库提供的同名 JSON 文件，或通过 `examples/run_sample_workflow.py` 中的降级逻辑在加载失败时自动切换。【F:hydrosis/config.py†L124-L152】【F:examples/run_sample_workflow.py†L35-L75】建议在 CI/CD 管道中保留 YAML 与 JSON 两份配置，以确保在无 PyYAML 环境下也能运行示例。

### A.3 情景与参数增量维护

`ModelConfig.apply_scenario` 支持在运行前对配置中列出的子流域批量覆写参数；若情景中未列出的子流域将保持基准参数不变。【F:hydrosis/config.py†L154-L192】维护情景时推荐遵循以下流程：

1. 在 `scenarios` 段落新增情景 ID，并确保 `modifications` 的键与子流域 ID 一致；
2. 若需新增模型组合，先在 `runoff_models`/`routing_models` 中注册对应 ID；
3. 调用 `ModelConfig.apply_scenario` 或高阶工作流入口（见附录 D）时传入该情景 ID。

### A.4 参数区扩展模板

在新增参数区时，可参考测试用例中的构建函数 `_build_workflow_config`，其示例展示了如何为不同控制点绑定参数区与情景改写，便于模拟中游减缓汇流的需求。【F:tests/test_workflow.py†L23-L114】通过在 `ParameterZoneConfig` 中提供 `parameters` 字典，即可让 `_assign_zone_parameters` 在模型实例化时自动同步到对应子流域。【F:hydrosis/model.py†L44-L51】

## 附录B API 参考速查

### B.1 顶层导出符号

包入口 `hydrosis/__init__.py` 暴露了最常用的类与函数，包括 `HydroSISModel`、`ModelConfig`、`run_workflow` 以及报告构建工具，方便在脚本中一次性导入核心接口。【F:hydrosis/__init__.py†L3-L32】

### B.2 核心类与方法

| 接口 | 主要用途 | 关键参数/返回值 |
| --- | --- | --- |
| `ModelConfig.from_yaml(path)` | 解析 YAML 配置并实例化模型配置对象，内部完成子配置的拆解与类型校验。【F:hydrosis/config.py†L124-L152】 | `path`: 配置文件路径；返回 `ModelConfig`。 |
| `HydroSISModel.from_config(config)` | 基于配置构建模型实例，完成子流域、参数区、产流与汇流模块的注册与绑定。【F:hydrosis/model.py†L52-L68】 | `config`: 已解析配置；返回 `HydroSISModel`。 |
| `HydroSISModel.run(forcing)` | 执行逐子流域的产流/汇流计算并返回局地流量序列，缺失模型 ID 将抛出异常。【F:hydrosis/model.py†L70-L92】 | `forcing`: 子流域到强迫数据的映射；返回局地流量字典。 |
| `HydroSISModel.accumulate_discharge(routed)` | 基于拓扑聚合上游流量，返回包含累积径流的序列。【F:hydrosis/model.py†L94-L97】 | `routed`: 子流域局地汇流结果；返回累积流量。 |
| `HydroSISModel.parameter_zone_discharge(routed)` | 提取各参数区控制点的累积流量，用于评价与报告展示。【F:hydrosis/model.py†L99-L115】 | 返回结构化的参数区 -> 控制点 -> 时序字典。 |
| `run_workflow(config, forcing, ...)` | 一键执行基准与情景模拟、可选评估与报告生成，适用于批量实验与自动化测试。【F:hydrosis/workflow.py†L168-L200】 | 支持 `scenario_ids`、`persist_outputs`、`generate_report` 等参数。 |

### B.3 评价与报告组件

`hydrosis/evaluation/metrics.py` 内置 RMSE、MAE、PBIAS、NSE 四种指标及其目标方向，可直接在配置文件 `evaluation.metrics` 中引用，也可通过 `SimulationEvaluator` 自定义扩展。【F:hydrosis/evaluation/metrics.py†L15-L94】报告模块 `MarkdownReportBuilder` 则提供段落、列表、表格、图像等写入方法，并可将最终文档保存为 Markdown。【F:hydrosis/reporting/markdown.py†L15-L75】在 `generate_evaluation_report` 中，这些组件会自动汇总指标、绘制图表并输出报告文件夹结构。【F:hydrosis/reporting/markdown.py†L150-L200】

### B.4 工作流扩展钩子

高阶工作流内部通过 `_build_evaluator`、`_evaluate_plan` 等私有函数拆解情景运行、指标计算与排名逻辑，必要时可在复制后的自定义脚本中覆写这些函数以满足特殊业务需求。【F:hydrosis/workflow.py†L75-L165】

## 附录C 数据字典

### C.1 输入数据目录

示例工程按 README 建议，在 `data/sample` 下组织 DEM、强迫数据、GIS 辅助信息与观测序列，便于脚本解析。【F:README.md†L83-L105】表 C-1 总结了默认目录与格式：

| 目录 | 内容 | 格式 | 说明 |
| --- | --- | --- | --- |
| `data/sample/dem` | 栅格高程模型 | GeoTIFF | 供流域划分模块读取。配置通过 `delineation.dem_path` 指向该文件。【F:config/example_model.yaml†L3-L8】 |
| `data/sample/gis` | 汇水点/河网矢量 | GeoJSON | 支持透传到流域划分流程或作为预处理参考。【F:config/example_model.yaml†L3-L8】 |
| `data/sample/forcing` | 子流域降雨或外部强迫 | CSV (`time,precipitation`) | 以子流域 ID 命名文件，时间步与降雨强度成对存储。【F:data/sample/forcing/SB1.csv†L1-L13】 |
| `data/sample/observations` | 出口或控制点观测流量 | CSV (`time,value`) | 默认由示例脚本自动生成轻微扰动的观测序列，用于精度评价。【F:data/sample/observations/SB4.csv†L1-L12】【F:examples/run_sample_workflow.py†L78-L123】 |

### C.2 输出目录

示例工作流运行后，会在 `results/example_run` 下按情景生成子目录，并在 `reports` 目录内写入 Markdown 报告及图件路径。【F:README.md†L87-L105】测试用例验证了 `run_workflow` 会在情景 ID 名称下创建 CSV 输出，并可选生成报告文件。【F:tests/test_workflow.py†L134-L168】

### C.3 参数区与子流域字段

`precomputed_subbasins` 列表中，每个子流域需声明 `id`、`area_km2`、`downstream` 和 `parameters` 四类字段；其中 `parameters` 中的键需匹配产流/汇流模型 ID，以便实例化时自动关联。【F:config/example_model.yaml†L8-L33】【F:hydrosis/model.py†L44-L90】

## 附录D 常用脚本与命令

### D.1 示例工作流脚本

`examples/run_sample_workflow.py` 演示了从配置加载、路径解析、强迫/观测读取、情景运行到报告生成的完整流程，可作为生产环境批处理脚本的雏形。【F:examples/run_sample_workflow.py†L35-L180】脚本末尾还打印基准情景的前五个时间步及指标，便于快速审查输出结果。【F:examples/run_sample_workflow.py†L164-L179】

## 附录E 名词缩写表

| 缩写 | 全称 | 在 HydroSIS 中的含义 |
| --- | --- | --- |
| DEM | Digital Elevation Model | 供流域划分使用的高程栅格数据，通过 `delineation.dem_path` 配置。【F:config/example_model.yaml†L3-L8】 |
| NSE | Nash-Sutcliffe Efficiency | 衡量模拟与观测吻合度的指标，`evaluation.metrics` 默认启用。【F:hydrosis/evaluation/metrics.py†L48-L77】【F:config/example_model.yaml†L123-L131】 |
| PBIAS | Percent Bias | 反映模拟相对观测的偏差百分比，可用于排名或合规判定。【F:hydrosis/evaluation/metrics.py†L34-L46】 |
| RMSE | Root Mean Square Error | 模拟误差的平方根均值，是最常用的精度指标之一。【F:hydrosis/evaluation/metrics.py†L15-L23】 |
| MAE | Mean Absolute Error | 评价模拟误差绝对值的平均水平，常用于稳健性对比。【F:hydrosis/evaluation/metrics.py†L25-L32】 |
| I/O | Input/Output | 输入输出配置段落，控制数据路径与成果目录。【F:config/example_model.yaml†L104-L109】 |
