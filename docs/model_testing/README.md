## 🔍 模型诊断

### HBV模型特点
✅ **优势**：
- 参数物理意义明确
- 适应性强，通用性好
- 计算稳定，不易发散
- 在所有分区表现优异

⚠️ **注意事项**：
- 需要温度数据（用于融雪，本测试使用默认15°C）
- 参数较多，需要充分率定
- 对初始状态敏感

### XinAnJiang模型特点
✅ **优势**：
- 适合中国湿润半湿润地区
- 蓄满产流机制合理
- 参数有明确物理意义

⚠️ **注意事项**：
- 本测试中表现中等（平均NSE=0.47）
- 对蒸发参数敏感
- 需要根据流域特征调整参数范围

### SCS-CN模型特点
✅ **优势**：
- 参数少（仅2个）
- 计算简单快速
- 在某些情况下R²很高

⚠️ **注意事项**：
- 系统性低估径流（平均RC误差0.20）
- NSE表现较差（平均0.30）
- 更适合单场降雨事件分析
- 不适合连续模拟
