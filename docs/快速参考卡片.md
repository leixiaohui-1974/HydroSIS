## ⚙️ 核心配置参数

### HBV参数
```yaml
hbv_parameters:
  FC: 300      # 田间持水量 (mm)
  BETA: 2.0    # 形状系数
  LP: 0.7      # 蒸散发阈值
  K0: 0.1      # 快速消退系数 (1/h)
  K1: 0.05     # 中速消退系数 (1/h)
  K2: 0.01     # 慢速消退系数 (1/h)
  PERC: 2.0    # 渗透速率 (mm/h)
  UZL: 50.0    # 上层水库阈值 (mm)
```

### 雨量站配置
```yaml
rain_gauge:
  target_density: 0.01    # 1站点/100km² (良好)
  min_distance_m: 1000    # 最小站间距
  random_seed: 42         # 可复现
```

### 并行配置
```yaml
parallel:
  max_workers: 4          # CPU核心数
  show_progress: true     # 显示进度
```

## 🔍 验证框架 API

### 降雨验证
```python
from hydrosis.validation import validate_precipitation_data

result = validate_precipitation_data(precip_df)
print(f"空间CV: {result.metrics['spatial_cv']}")
```

### 径流系数验证
```python
from hydrosis.validation import validate_runoff_coefficient

result = validate_runoff_coefficient(rc=0.65)
assert result.is_valid  # 0 ≤ RC ≤ 1
```

### 水量平衡验证
```python
from hydrosis.validation import validate_water_balance

result = validate_water_balance(
    precipitation_mm=500,
    runoff_mm=325,
    evapotranspiration_mm=150,
    storage_change_mm=20,
    tolerance=0.05  # 5%容差
)
```

## 📊 验证标准阈值

| 指标 | 阈值 | 说明 |
|-----|------|------|
| **径流系数 RC** | 0.0 - 1.0 | 超出此范围物理不合理 |
| **空间CV** | < 0.5 | 降雨空间分布均匀性 |
| **站点相关性** | > 0.3 | 站点间数据相关性 |
| **缺测率** | < 10% | 数据完整性 |
| **连续零值** | < 24h | 异常长时间无雨 |
| **水量平衡误差** | < 5% | P ≈ R + ET + ΔS |

## 🎯 雨量站密度等级

| 等级 | 密度 (站点/100km²) | 适用场景 |
|-----|-------------------|---------|
| **优秀** | ≥ 0.02 | 研究级、高精度 |
| **良好** | 0.01 - 0.02 | 业务化模拟 |
| **一般** | 0.005 - 0.01 | 粗略模拟 |
| **较差** | < 0.005 | 仅初步评估 |

**地形修正**: 平原×0.8 | 丘陵×1.0 | 山地×1.5 | 高山×2.0

## 🛠️ ValidationResult 对象

```python
result = ValidationResult(step_name="降雨验证")

# 添加结果
result.add_error("严重问题")      # 导致 is_valid=False
result.add_warning("轻微问题")    # 不影响 is_valid

# 记录指标
result.metrics['spatial_cv'] = 0.35
result.metrics['mean_precip'] = 450.2

# 检查状态
if result.is_valid:
    print("✓ 验证通过")
else:
    print(f"✗ 失败: {result.errors}")
```

## 📈 性能参考 (HBV并行)

| 分区数 | 时间步 | 串行时间 | 并行时间(4核) | 加速比 |
|-------|--------|---------|--------------|--------|
| 10 | 120 | 5.2秒 | 3.1秒 | 1.68x |
| 50 | 120 | 26.5秒 | 8.9秒 | 2.98x |
| 100 | 120 | 53.1秒 | 15.7秒 | 3.38x |
| 200 | 240 | 212.3秒 | 61.2秒 | 3.47x |

**建议**: <10分区用串行，10-50用2-4核，>50用4-8核

## 🔧 常见问题快速解决

### 径流系数 > 1
```bash
# 运行诊断
python diagnose_zone2_precipitation.py

# 检查: spatial_cv是否 > 0.5
# 解决: 改进降雨插值或使用实测数据
```

```python
# 查看详细信息
result = validate_precipitation_data(df)
print(result)  # 显示所有errors/warnings/metrics

# 调整标准 (如果合理)
criteria = PrecipitationCriteria(max_spatial_cv=0.7)
result = validate_precipitation_data(df, criteria)
```

```python
perf = benchmark_parallel_performance(
    zones, precip, hbv_params,
    worker_counts=[1, 2, 4, 8]
)
# 选择最快的worker数量
```

## 💡 开发原则

1. **零硬编码**: 所有参数从YAML加载
2. **验证为先**: 关键步骤集成验证
3. **配置驱动**: 通过配置文件控制行为
4. **模块化**: 单一职责、清晰接口

---

## 🔑 关键概念

- **RC (径流系数)**: 径流量/降雨量，必须0-1
- **CV (变异系数)**: 标准差/均值，评估空间均匀性
- **ValidationResult**: 统一验证结果容器
- **ValidationCriteria**: 可配置验证标准基类
- **配置驱动**: 从YAML文件加载所有参数
- **并行化**: ProcessPoolExecutor多核并行
