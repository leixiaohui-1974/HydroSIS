# HydroSIS 云服务架构 - 快速参考手册

本文档提供关键信息的快速查阅，详细内容请参考完整方案文档。

---

## 1. 架构概览

```
用户 → 阿里云前端 → 阿里云API → 通义千问 (理解意图)
                            ↓
                     MCP协议调用
                            ↓
                     本地MCP服务器 → HydroSIS计算引擎
```

**核心组件**：
- **阿里云侧**：前端 + API网关 + 通义千问 + RDS + OSS + Redis
- **本地侧**：MCP Server + HydroSIS + Kubernetes + MinIO + PostgreSQL

**通信协议**：MCP (Model Context Protocol)

## 2. 技术栈速查

### 阿里云服务
| 服务 | 用途 | 规格建议 |
|------|------|----------|
| ECS | 应用服务器 | ecs.c6.2xlarge × 6 |
| 函数计算FC | 无服务器函数 | 1GB内存 |
| RDS | PostgreSQL数据库 | rds.pg.s3.large |
| OSS | 对象存储 | 标准存储 |
| Redis | 缓存 | 1GB主节点 |
| API网关 | 接口管理 | 共享实例 |
| 通义千问 | 大模型 | qwen-max/qwen-plus |

### 本地服务
| 组件 | 技术选型 | 部署方式 |
|------|----------|----------|
| 容器编排 | Kubernetes | 3节点集群 |
| API框架 | FastAPI | Docker容器 |
| 任务队列 | Celery + Redis | Worker副本 |
| 对象存储 | MinIO | 持久化存储 |
| 数据库 | PostgreSQL | StatefulSet |
| 监控 | Prometheus + Grafana | Helm部署 |

## 3. MCP工具清单

### 核心工具（8个）

| 工具名称 | 功能 | 耗时 |
|---------|------|------|
| `create_project` | 创建水文项目 | ~1秒 |
| `delineate_watershed` | 流域划分 | 30秒-5分钟 |
| `configure_runoff_model` | 配置产流模型 | ~1秒 |
| `upload_forcing_data` | 上传降雨数据 | 5-30秒 |
| `run_simulation` | 运行模拟 | 1-10分钟 |
| `calibrate_parameters` | 参数校准 | 10-60分钟 |
| `analyze_results` | 结果分析 | 10-30秒 |
| `generate_gis_report` | 生成GIS报告 | 30秒-2分钟 |

### 调用示例

```python
# 工具调用格式
{
    "name": "delineate_watershed",
    "arguments": {
        "project_id": "proj_12345",
        "dem_path": "users/user001/dem.tif",
        "pour_points": [
            {"id": "outlet1", "lon": 120.15, "lat": 30.25}
        ]
    }
}
```

## 4. API端点速查

### 阿里云API（https://api.hydrosis.com）

```
# 认证
POST   /api/v1/auth/register      # 用户注册
POST   /api/v1/auth/login         # 用户登录
POST   /api/v1/auth/refresh       # 刷新Token

# 对话
POST   /api/v1/chat/conversations           # 创建对话
POST   /api/v1/chat/conversations/{id}/messages  # 发送消息
GET    /api/v1/chat/conversations/{id}      # 获取对话历史
WS     /ws/chat/{user_id}                   # WebSocket连接

# 项目管理
GET    /api/v1/projects                     # 列出项目
POST   /api/v1/projects                     # 创建项目
GET    /api/v1/projects/{id}                # 获取项目详情
PUT    /api/v1/projects/{id}                # 更新项目
DELETE /api/v1/projects/{id}                # 删除项目

# 任务管理
POST   /api/v1/tasks                        # 提交任务
GET    /api/v1/tasks/{id}                   # 获取任务状态
GET    /api/v1/tasks/{id}/result            # 获取任务结果
WS     /ws/tasks/{task_id}                  # 任务进度推送

# 文件上传
POST   /api/v1/upload                       # 上传文件
GET    /api/v1/files/{path}                 # 下载文件
```

### MCP服务API（http://mcp.hydrosis.local）

```
# MCP协议端点
GET    /mcp/tools                           # 列出所有工具
POST   /mcp/tools/{tool_name}               # 调用工具
GET    /mcp/resources/{resource_uri}        # 获取资源
GET    /mcp/prompts                         # 列出提示词模板

# 健康检查
GET    /health                              # 健康状态
GET    /ready                               # 就绪状态
GET    /metrics                             # Prometheus指标
```


## 7. 部署命令速查

### 阿里云部署

```bash
# 构建镜像
docker build -t hydrosis/app:latest -f Dockerfile.app .

# 推送到ACR
docker push registry.cn-hangzhou.aliyuncs.com/hydrosis/app:latest

# 更新函数计算
aliyun fc UpdateFunction --serviceName hydrosis --functionName chat-handler

# 上传前端到OSS
ossutil cp -r dist/ oss://hydrosis-public/web/ --update --recursive

# 刷新CDN
aliyun cdn RefreshObjectCaches --ObjectPath https://www.hydrosis.com/
```

### 本地K8s部署

```bash
# 创建命名空间
kubectl create namespace hydrosis

# 应用配置
kubectl apply -f k8s/configmap.yaml
kubectl apply -f k8s/secrets.yaml

# 部署服务
kubectl apply -f k8s/deployment-mcp.yaml
kubectl apply -f k8s/service-mcp.yaml

# 查看状态
kubectl get pods -n hydrosis
kubectl logs -f deployment/hydrosis-mcp-server -n hydrosis

# 扩容
kubectl scale deployment hydrosis-mcp-server --replicas=5 -n hydrosis
```

## 8. 监控告警

### 关键指标

| 指标 | 正常范围 | 告警阈值 | 严重阈值 |
|------|----------|----------|----------|
| API响应时间(P95) | < 1s | > 3s | > 5s |
| 错误率 | < 0.1% | > 1% | > 5% |
| CPU使用率 | < 50% | > 70% | > 90% |
| 内存使用率 | < 60% | > 80% | > 95% |
| 任务队列长度 | < 10 | > 50 | > 100 |
| 磁盘使用率 | < 70% | > 85% | > 95% |

### Prometheus查询

```promql
# 请求QPS
rate(http_requests_total{job="hydrosis-mcp"}[1m])

# P95延迟
histogram_quantile(0.95, rate(http_request_duration_seconds_bucket[5m]))

# 错误率
rate(http_requests_total{status=~"5.."}[5m]) / rate(http_requests_total[5m])

# 活跃任务数
celery_active_tasks{job="hydrosis-worker"}
```

## 9. 故障排查

### 常见问题

#### 1. MCP工具调用失败

```bash
# 检查MCP服务状态
kubectl get pods -n hydrosis | grep mcp

# 查看日志
kubectl logs -f deployment/hydrosis-mcp-server -n hydrosis --tail=100

# 测试连接
curl http://mcp.hydrosis.local/health

# 检查认证
curl -H "Authorization: Bearer <token>" http://mcp.hydrosis.local/mcp/tools
```

#### 2. 任务执行超时

```bash
# 查看Worker状态
kubectl get pods -n hydrosis | grep worker

# 查看Celery队列
celery -A mcp_server.tasks inspect active
celery -A mcp_server.tasks inspect reserved

# 查看任务详情
kubectl logs deployment/hydrosis-worker -n hydrosis | grep task_id
```

#### 3. 数据库连接问题

```bash
# 测试数据库连接
psql -h postgres -U hydrosis -d hydrosis -c "SELECT 1"

# 查看连接数
SELECT count(*) FROM pg_stat_activity WHERE datname='hydrosis';

# 查看慢查询
SELECT query, mean_exec_time FROM pg_stat_statements 
ORDER BY mean_exec_time DESC LIMIT 10;
```

#### 4. 存储空间不足

```bash
# 检查OSS使用量
ossutil du oss://hydrosis-user-data/

# 清理临时文件
ossutil rm oss://hydrosis-user-data/temp/ -r

# 检查MinIO使用量
mc du minio/hydrosis-projects

# 清理旧数据
kubectl exec -it deployment/hydrosis-mcp-server -n hydrosis -- \
  python -c "from cleanup import clean_old_files; clean_old_files(days=90)"
```
